# Proposed assurance obligations

### OBL-001 — actual execution binding

Scope: a bounded CPU PlanSpec through the public producer. Evidence: actual execution and native artifact references; refusal for wrong Dispatch, plan, registry, job and attempt. No distributed claim.

### OBL-002 — signature and source integrity

Scope: exact provider envelope bytes and caller-established trusted key. Evidence: a valid public verification and altered payload, signature, key, duplicate-field and retained-source refusal controls.

### OBL-003 — terminal distinctions

Scope: producer outcomes from execute_plan. Evidence: clean success, warnings, cancellation, deadline and failure observations; no invented completion from a running or failed attempt.

### OBL-004 — authority boundary

Scope: this adapter. Evidence: no acceptance/authorization/signing act for OpenWarrant, no invented confinement or cost, and explicit UNKNOWN when native evidence or collector trust is unavailable.
