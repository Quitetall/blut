# blut-types

Wasm-safe wire and content-addressing types shared by BLUT engine and its
sidecars. This crate intentionally excludes runtimes, filesystems, databases,
and domain-specific training code.

Version follows BLUT public preview release train. Depend on exact preview
versions until 1.0:

```toml
blut-types = "=0.2.0-alpha.1"
```
